Collega La Scatola a GitHub

Lettere di benvenuto · Chalet Hotel Hartmann. Si fa una volta: dopo, GitHub aggiorna da solo gli arrivi ogni ora.

Manca il client_id

L'amministratore della Scatola deve prima registrare questo collegamento (client OAuth con PKCE, indirizzo di ritorno https://alpstay.github.io/WelcomeHartmann/collega.html, permesso sullo Chalet Hartmann). Il client_id che ti dà va scritto nel file scatola-client.json.

1. Accedi a La Scatola

Usa il tuo account della Scatola con il permesso sullo Chalet Hartmann. Poi torni qui.

2. Salva i due valori su GitHub

Questi valori danno accesso ai dati degli ospiti: non inviarli a nessuno e chiudi la pagina quando hai finito. Non vengono salvati da nessuna parte.

  1. Apri GitHub → Settings → Secrets and variables → Actions → New repository secret.
  2. Crea un segreto per ciascuna riga qui sotto: nome uguale, valore copiato con «Copia».
  3. Solo la prima volta: segreto ARRIVI_PASSWORD con la password reception della pagina.
  4. Apri Actions → «Aggiorna arrivi» e premi Run workflow.
